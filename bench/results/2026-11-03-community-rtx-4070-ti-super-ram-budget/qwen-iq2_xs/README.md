# Original Qwen IQ2_XS replication — RTX 4070 Ti SUPER

Measured Nov 4, 2026 by fm5454 with assistance from Sol 6.1 Sol High
(contributor-supplied assistant label). This follows the [Swift test](../swift-report.md)
on the same GPU, CPU, usable RAM, NVMe drive and prebuilt CUDA engine 0.1.56.
Windows build 26300.9711 (26H2), NVIDIA driver 617.42. Engine binary digest and
hardware metadata are in [hardware.json](hardware.json).

The installed model is original `ISTA-DASLab/Qwen3.8-Flash-Next-GSQ-RCO-GGUF`,
revision `ed59f92082b1e93c0e96d60a8b11aab089b52f09`, IQ2_XS.
[model-provenance.json](model-provenance.json) records both installer-verified
GGUF SHA-256 values, native pack metadata and expert-profile digest. Its
`transport_etag` is a download identity, not a content SHA-256. Native pack and
tokenizer were generated by the installed setup. Source-model and independent
tokenizer revision were not captured. No custom control vector was added.

## Method

Swift's files were removed after backing up its configuration. The replacement
model kept 128K capacity, INT8 KV without streaming, MTP depth 4, confidence 0.5,
auto expert cache / prefill, mmap mode, 1,536 MiB reserve, CPU vision (8 threads,
300 image-token cap), and one request at a time. The model's own weights, native
pack and vision encoder replaced Swift's paths. Both conditions used the same
installed expert profile. Compare [baseline-config.json](baseline-config.json)
with [resident14-config.json](resident14-config.json); only the resident budget
argument differs. These are sanitized effective excerpts, not runnable configs.

[qwen_prefill_ab.py](qwen_prefill_ab.py) starts a fresh isolated worker per
condition using the installed server/lifeline, selects an ephemeral loopback port,
waits for health, makes requests, and stops its own worker. The normal app had no
model loaded. `STRATA_NO_PRESET=1` bypassed saved tuner presets. Sequence:
six baseline requests, six budget requests, then a fresh budget stress worker.
No separate warm-up was used; adaptation continued within each condition.
The OS file cache was not flushed and desktop background load was uncontrolled.

Main A/B calls used three 4K targets then three 16K targets, `max_tokens=8`,
temperature 0, non-streaming, `strata_checkpoint=false`, and default thinking.
Eight-token completions can remain in thinking; no answer quality or decode gain
is inferred. Prompt generation follows the first test's synthetic records but
uses fixed per-case reference tags and 4.25 characters per target token, without
cross-request calibration. The exact text/hash and actual token count match
between A and B. All 14 performance requests reported zero cached prompt tokens.
Prompt files are included; hashes cover UTF-8 logical text after newline
normalization as read by Python, not necessarily checkout bytes on Windows.

Executed with the installed bundled Python, with private paths abbreviated:

```text
python qwen_prefill_ab.py --config <installed-model-config> --out <evidence-dir> --condition baseline
python qwen_prefill_ab.py --config <installed-model-config> --out <evidence-dir> --condition resident14
python qwen_prefill_ab.py --config <installed-model-config> --out <evidence-dir> --condition resident14 --stress --recall
```

Private worker configs with ephemeral keys are excluded. Engine logs and
published config excerpts replace local path roots with placeholders. Use a
private full config when repeating these commands; the runner reads its `cwd`
to locate the installed server and leaves the source config unchanged.

## Memory, validation and limits

Available RAM was sampled every 0.5 s with Strata's `tune_machine.memory()` /
Windows `GlobalMemoryStatusEx`, separating startup from inference. Full samples
are retained in `*-memory.json`; minima during inference were baseline
6 MiB, budget 5,908 MiB, and stress plus
recall 5,893 MiB. These are sampled system-available
memory, not process RSS or a complete paging/commit trace. Logs retain memory
warnings, CPU-buffer fallbacks, GPU slot counts and parked-cache decisions.

Passed: 12 A/B requests, two stress performance requests, and one recall
request completed. No inference request failed or was cancelled. Offline
[verify_qwen_evidence.py](verify_qwen_evidence.py) checks counts, matched inputs,
timing arithmetic, the sole argument delta, context/KV and fixture hashes.

Not run: standard benchmark, natural documents, budget sweep, unrelated
architectures, different GPUs/OSes, full 131,072-token input, broad quality or
concurrency tests, or a source build. The two tested weight sets share an
architecture and quantization. Only this second test captures binary/model
digests and identical pairwise prompt hashes. The intentional budget change
also selects unbuffered file-tier reads; no claim isolates residency from I/O.
