### 1. Incorrect ASS Color Format (Alpha Channel)
**Lines:** `_ass_colour` function
**Problem:** The ASS color format is `&HAABBGGRR`. The code places the alpha value in the first two hex digits (`AA`), but standard ASS implementations often expect the alpha to be inverted or handled differently depending on the renderer, but more critically, the format string `f"&H{alpha:02X}..."` produces `&H00RRGGBB` for opaque. However, the standard ASS color format is actually `&HAABBGGRR` where `AA` is alpha (00=opaque, FF=transparent). The code is technically correct for the format string, but `st['bg']` is passed with `0x40` alpha. The bigger issue is that `st['fg']` and `st['accent']` are passed with default `alpha=0`. If `st['fg']` is `#FFFFFF`, it becomes `&H00FFFFFF`. This is correct.
