### 1. Incorrect ASS Color Format (Bug)
**Lines:** `_ass_colour` function
**Problem:** The ASS color format is `&HAABBGGRR` (Alpha, Blue, Green, Red). The current code outputs `&H{alpha}{RR}{GG}{BB}`, which swaps Red and Blue channels, resulting in incorrect colors (e.g., red text appearing blue).
**Fix:**
```python
def _ass_colour(hexcolor: str, alpha: int = 0) -> str:
    """'#RRGGBB' -> ASS '&HAABBGGRR' (alpha 0 = opaque, 255 = invisible)."""
    c = (hexcolor or "#FFFFFF").lstrip("#")
    # Correct order: Alpha, Blue, Green, Red
    return f"&H{alpha:02X}{c[4:6]}{c[2:4]}{c[0:2]}"
```
