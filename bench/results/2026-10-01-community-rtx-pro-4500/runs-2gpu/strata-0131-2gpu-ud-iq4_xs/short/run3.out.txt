### 1. Incorrect ASS Color Format (Bug)
**Lines:** `_ass_colour` function
**Problem:** The ASS color format is `&HAABBGGRR` (Alpha, Blue, Green, Red). The code incorrectly maps the hex string `#RRGGBB` by slicing `c[4:6]` (Blue) into the Alpha position, `c[2:4]` (Green) into Blue, and `c[0:2]` (Red) into Green. This results in wrong colors and incorrect alpha handling.
**Fix:**
```python
def _ass_colour(hexcolor: str, alpha: int = 0) -> str:
    """'#RRGGBB' -> ASS '&HAABBGGRR' (alpha 0 = opaque, 255 = invisible)."""
    c = (hexcolor or "#FFFFFF").lstrip("#")
    # Input is RRGGBB. Output needs AABBGGRR.
    # Alpha is provided separately.
    r, g, b = c[0:2], c[2:4], c[4:6]
    return f"&H{alpha:02X}{b}{g}{r}"
```
