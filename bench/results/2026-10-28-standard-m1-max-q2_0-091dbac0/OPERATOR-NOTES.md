# Operator additions and erratum

This file supplements, and does not rewrite, the unmodified output of `strata bench run`.

## Erratum: vision setting

The operator's `--track-notes` incorrectly says `vision off`. The actual setup-generated configuration and engine startup command enable `--vision`, and the GPU vision helper was loaded and warmed. See `config.json`, `engine.log`, and `results.json` at `extensions.other_engine_options`. No image requests were made. Vision quality and latency were not measured. All other settings are those generated by the official installer; no engine code was modified.

## Hardware, load and memory

- MacBookPro18,2, Apple M1 Max: 10 CPU cores (8 performance + 2 efficiency), 32 GPU cores, 64 GiB shared unified memory. Do not add GPU shared memory to system memory again.
- Model storage: internal NVMe APPLE SSD AP1024R, 1,000,555,581,440 bytes. PCIe link rate/width not measured. The GPU is integrated.
- macOS 26.6.2, build 25G83; AC power; AC powermode 0. GPU power cap, clocks, temperature and instantaneous power not measured.
- Daily-driver desktop: Chrome, Adobe background services, WindowServer, Stats, Tailscale, oMLX and OS background work were not terminated. No inference requests were sent to oMLX by this benchmark; its post-run health check reported zero loaded models. Background CPU/GPU effects are not fully controlled.
- Approximately 5-second host sampling produced 102 samples covering loading, hashing and inference. Highest observed engine RSS was 42,211,966,976 bytes (39.313 GiB); highest observed vision-helper RSS was 1,233,092,608 bytes (1.148 GiB). These are sampled process RSS values, not exact peaks or dedicated GPU allocations. Shared mappings must not simply be summed.
- `sysctl vm.swapusage` reported 291.31 MiB used at the first, last and maximum observed samples. This is rounded reporting and includes pre-existing swap, not proof of zero paging.

## Interpretation and checks

Every performance request reported zero cached prompt tokens; freshly processed counts equaled input counts. The engine disabled conversation caching and logged that its available-RAM guard could not read RAM. Expert/page caches and kernel state remained warm within the run. The generic cache wording in the auto-generated README should be read in light of these actual zero-reuse records.

The engine's fallback PCIe fraction is not a bandwidth measurement. RAM-guard and PCIe-probe diagnostics remain in `engine.log`. No benchmark request failed or was skipped. Four of nine performance requests reached the 512-token cap; one 16K request had no final-answer delta. Its missing first-answer latency is excluded from that metric only, leaving n=2 there. The warmup also reached its own 128-token cap and is excluded from speed statistics.

The official `strata bench report` validation succeeded. A separate local verifier reconstructed all 15 summary groups, checked six artifact hashes and 22 unique request records, and rescored the twelve sanity cases from saved final outputs/tool calls using the frozen fixtures: 12/12. No inference was rerun for verification.

The protocol remains `strata-qwen38-thinking-v1-draft.1`. This is a local measurement, not maintainer approval or an independent hardware replication. Optional concurrency, images, larger contexts, soak and full coding evaluations were not measured.
