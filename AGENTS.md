# Project agent contract

- Follow the task; inspect existing code, instructions and CI before editing.
- Read `.agentic/workflow.md` for delivery and verification expectations.
- Keep changes scoped; preserve unrelated work and existing authorization.
- Run `python3 .agentic/verify.py` for configured project verification.
- An unconfigured or failed check is not a successful verification.
- Report changed behavior, checks run, remaining failures and limitations.
