libgomp.so.1: the GNU OpenMP runtime library, part of the GCC runtime

This engine package carries an unmodified copy of libgomp.so.1 from the build machine. The Inkling-2 runner strata-inkling in this
package needs it (its CPU expert kernels run in OpenMP parallel loops), and some Linux systems (containers, minimal installs) do
not have it.
