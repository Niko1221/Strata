# Qualify Unreal Device

Use the exact target build, platform and test map. Verify the user-facing entry point and representative interactions in a packaged run. For XR input, exercise the normal hand or controller path, including the panel-closed case where relevant. Record visible overlays, runtime behavior and measured device results with distinct evidence.

Report technical checks, actual device observation and human acceptance separately. If device access is absent, retain the concrete pending check and what can already be concluded from the isolated build.
