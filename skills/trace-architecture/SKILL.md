# Trace Architecture

Pin the project, revision, and evidence boundary. Follow the recorded links from requirement to component or function, behavior model, source symbol, and test or observation. Preserve native UML, SysML, PDL, PML, SAD, and ADR identities. Label each link as recorded, proposed, or unresolved. A generated diagram establishes that it rendered. Semantic coverage needs a matching source or runtime trace.

Report the first broken link for each selected requirement, its impact, and the smallest check or correction that can close it. Mark the parts you sampled and the parts that remain uninspected.
