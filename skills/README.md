# Workflow skills for Strata

In Strata, open **Skills → Add skill** and select the folder for the workflow you want, such as `resume-worktree`. Each folder contains one self-contained `SKILL.md`. Import individual folders as needed. Describe the task in the chat or use the skill name to identify the desired workflow.

| Software and delivery | [Clarify open decisions](clarify-open-decisions/SKILL.md), [Resume a worktree task](resume-worktree/SKILL.md), [Maintain a project plan](maintain-project-plan/SKILL.md), [Implement a software change](implement-software-change/SKILL.md), [Review an upstream change](review-upstream-change/SKILL.md), [Diagnose runtime integration](diagnose-runtime-integration/SKILL.md), [Qualify a build and release](qualify-build-and-release/SKILL.md) |
| Science | [Design a study](design-science-study/SKILL.md), [Curate Science evidence](curate-science-evidence/SKILL.md) |
| Business | [Reconcile a business plan](reconcile-business-plan/SKILL.md), [Prepare a business decision](prepare-business-decision/SKILL.md) |

Each skill resolves project rules, routes, and evidence from the active workspace. Live writes, deployment, and external submissions follow the user's authorization. During testing, look for the invoked skill in the chat and verify the resulting artifact or receipt.
