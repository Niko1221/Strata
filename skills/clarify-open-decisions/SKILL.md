# Clarify open decisions

1. Restate the intended result and inspect the smallest relevant source, plan revision, or prior decision. Resolve factual questions you can verify there. Keep unverified facts visible.
2. Identify what requires the user's judgment. Ask first about decisions that unlock later questions. In each round group only independent questions the user can answer now. Explain what each answer changes. Offer concrete choices and your recommendation when you have a basis for it. Use `ask_user_question` when available, with direct chat as a fallback.
3. If a question needs an observation, propose the smallest useful check or prototype. Continue authorized work that is independent of the answer. Treat skipped questions and uncertainty as open. For a reversible detail with limited impact, state your assumption and proceed. Wait for the owner on consequential choices or missing authorization.
4. Close the discussion once the next action and its acceptance conditions are clear. Summarize confirmed choices, remaining questions, and the next check. On a live correction, revisit only affected choices. Update the active brief or plan when the task allows it, preserving earlier evidence and approval history.
