# Review Upstream Change

Read the exact diff and its callers, then compare the target revision and installed files. Check interaction with local changes through a read-only merge simulation or isolated checkout. Trace any changed API, counters, settings, or persisted state to their consumers. Reproduce actionable findings with the smallest safe fixture.

Report impact, triggering conditions, and evidence. Give measured speed claims only from a matched comparison. Separate a clean merge from verified behavior. Keep upstream publication and installation within the user's authorization.
