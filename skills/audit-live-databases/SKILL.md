# Audit Live Databases

Use the registered read-only route per project. Read the advertised catalog and schema before sampling. Include supported sections beyond those named in the request. Track missing orders, links, revisions, and evidence separately from empty sections. Recheck representative relationships and source pins. An item count measures inventory size. Completeness requires coverage against current requirements and sources.

Report each route, project, coverage and concrete gaps. Mark failed or unavailable reads as unknown and preserve the error. Keep exports identified as dated views of the live source.
