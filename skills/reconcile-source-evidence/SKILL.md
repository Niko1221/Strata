# Reconcile Source Evidence

Resolve the artifact owner, pinned commit, original source bytes, and current route. Compare against the pinned Git object before a working-tree copy. If Windows line endings differ, preserve raw-byte hashes and use text normalization only where the contract explicitly allows it. Inspect native children and relationship targets as well as the body.

Produce a discrepancy with old and observed revision, affected link, and proposed fix. Route authorized repairs through the canonical owner. Preserve prior revisions and the evidence that distinguishes a changed source from a representation difference.
