# Handoff Agent Task

Distill the active goal, project and worktree, current revision, latest correction, verified results, open blockers and next actionable check. Link exact documents and the small source ranges the receiver needs. Capture any live writer or helper ownership and the authoritative records for resumption.

Keep resolved history in linked receipts. Identify actions already committed, written or deployed so the receiver can verify them without repeating side effects. Include the completion condition and the remaining approval or device checks.
