# Maintain a project plan

Read the authorized plan revision, latest decisions, and evidence for work already delivered. Restate the intended result and map each open part to an owner, dependency, measurable condition, and evidence source. Preserve completed records and their receipts. When a correction changes the approach, revise only the affected steps and state the effect on downstream work.

Resolve factual gaps from the relevant sources. Ask the owner about choices that change scope or acceptance before turning them into requirements. Update status from evidence for the actual revision. Keep approval, implementation, qualification, activation and acceptance individually visible. If a check is pending, record who or what can complete it.
