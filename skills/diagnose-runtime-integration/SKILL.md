# Diagnose runtime integration

Follow the user's real entry point through the launcher, active configuration, process, backend route, and client. Match executable builds and ports to receipts. Check the authoritative configuration before changing individual service files. Use timestamps to locate the first boundary where expected input or output stops. Preserve active workers and assigned device sessions.

Measure a representative end-to-end turn or command and repeat the original failure path after an authorized correction. Record the layer that failed, the observable result, and any device or user check still pending.
