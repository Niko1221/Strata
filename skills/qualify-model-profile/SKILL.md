# Qualify Model Profile

Pin model and engine digests, native context and output caps, effective reasoning, RAM policy and competing workloads. Use matched prompts and tool schedules where feasible. Record cold prefill separately from continuation time. Count reread tokens, RAM and SSD cache transitions, helper completions, and task correctness. Report actual auto-cache allocation.

Compare a context optimizer across a run that reaches the compaction threshold and inspect evidence retained after compaction. Label selection or fallback explicitly. Recommend a setting for the measured profile and give the limits of the comparison.
