# Meeting notes

Write the protocol in the language of the notes.

## Structure

Always use this template:

```
# <Topic> – <date if known>
## Decisions
- ...
## Action items
| What | Who | By when |
## Open questions
- ...
```

## Rules

- A decision is only what the notes show as agreed. A proposal nobody confirmed goes to "Open questions".
- Every action item has an owner. If the notes name none, write "unassigned" rather than guessing: a wrong owner is worse than none.
- Dates: keep what the notes say ("next Friday"); add the absolute date only when the meeting date is known.
- Leave out small talk and repeated points. The protocol should be readable in one minute.
