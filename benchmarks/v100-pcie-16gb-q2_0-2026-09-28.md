# NVIDIA Tesla V100-PCIE-16GB — Q2_0

Measured on 2026-09-28 with Qwen3.8-Flash-Next Q2_0 and Strata engine 0.1.20 plus the V100 prefill fast path.

## System

| Component | Configuration |
| --- | --- |
| GPU | NVIDIA Tesla V100-PCIE-16GB (`sm_70`), single GPU |
| CPU | AMD Ryzen 5 3600, 6 cores |
| Memory | 48 GB DDR4-3200 |
| Storage | NVMe SSD, model resident on disk |
| Software | Linux, CUDA 12.8 |
| Context and KV cache | 262,144 tokens, int8 KV |
| Runtime | Automatic prefill, five CPU pool workers, 0.28 PCIe fraction, MTP `--spec 4`, 0.70 draft floor |

## Results

Each row was a separate uncached request with a unique prefix and 64 generated tokens. Engine timing from `/metrics` supplied the exact prompt size and throughput.

| Prompt label | Exact prompt tokens | Prompt time | Prompt processing | Output generation | GPU hit rate |
| --- | ---: | ---: | ---: | ---: | ---: |
| ~4K | 4,143 | 4.19 s | 989.1 tok/s | 49.3 tok/s | 84.4% |
| ~4K | 4,376 | 4.34 s | 1007.5 tok/s | 52.1 tok/s | 86.5% |
| ~8K | 8,785 | 9.09 s | 966.5 tok/s | 50.6 tok/s | 88.0% |
| 32K | 29,527 | 25.97 s | 1136.8 tok/s | 50.5 tok/s | 88.7% |
| 128K | 117,837 | 178.72 s | 659.3 tok/s | 44.9 tok/s | 88.4% |
| 256K | 256,076 | 618.39 s | 414.1 tok/s | 38.8 tok/s | 84.3% |

The passively cooled card throttled after sustained load. Its ~8K prompt result ranged from 616 to 967 tok/s depending on temperature; the table uses the cool-idle measurement. Three cool-card repetitions measured 967.0, 965.0, and 966.5 tok/s.
