# Community RTX 4060 Ti 16 GB + 64 GB DDR5 — IQ3_S 512K and 1M

Strata version: **engine 0.1.62 / Control 0.1.62**.

Hardware: **one RTX 4060 Ti 16 GB** — NVIDIA's weakest 16 GB desktop GPU (4,352 CUDA cores, 128-bit, 288 GB/s) — plus **64 GB DDR5-6000**. The iGPU was the primary display adapter; browsers, Electron and desktop apps were pinned to it so the whole 4060 Ti stayed available to Strata. VRAM OC `nvidia-smi -lmc 10827`; boot unlock via nv-uefi-unlocker 2.1.8 with `plm_open=true`.

Model: `Qwen3.8-Flash-Next-GSQ-RCO-GGUF:IQ3_S` from ISTA-DASLab, 125B MoE (~6B active), with the tuned DFlash2 draft pack. The model card's near-BF16 task average (93.26 vs 93.12) is why IQ3_S was used rather than a smaller quant.

Method: realistic, non-repeating long prompts generated by `tools/prefill_real_bench.py`, cold cache, temperature 0 on the benchmark client. `max_tokens` was 64 for the 40k samples, 256 for the 512k long ramp and 64 on the 1M ramp. These are engine prefill t/s, **not TTFT**, and they are not a `strata bench run` protocol result. Decode figures are short-answer samples, not long-output decode records.

## Measured runs

| Preset | Window | Prefill | Decode |
| --- | ---: | --- | --- |
| `strata-512k-routed` | 524,288 | **2,100.5 t/s median / 2,104.8 t/s peak @ ~41k**; 1,647.7 t/s @ 500k | 53.3 t/s median / 58.4 t/s peak @40k (n=3); 42.2 / 45.2 / 42.4 t/s @ 200k / 350k / 500k |
| `strata-1m-h4` | 1,048,576 | 1,686.4 @40k; 1,767.8 @256k; **1,253.7 @1,000,807 tokens** | 32.2 @40k; 34.8 @256k; 33.3 @1M |

The 1M ramp completed 40k → 256k → 1,000,807 tokens with zero breaks; the engine remained `loaded` with `n_ctx 1048576`.
