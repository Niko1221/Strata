# Attention промпта на тензорных ядрах (пилот FA)

Референсная машина: RTX 3060 Ti 8 ГБ, 32 ГиБ RAM, KAT IQ4_XS (qwen35moe), KV q4_0.
Ветка `fa-mma`, база `main` 8ee1f346. Статус: пилот, гейты G1–G5 ниже.

## Зачем

На промпте 96k cuBLAS-ветка attention (`q36_engine.cu`, путь `T > kGemmT`) материализует
скоры и режет запросы так, чтобы влез буфер скоров: при `--att-mb 256` чанк 2048 на хвосте
префикса 86k — это ~43 среза, ~900 срезов на слой и ~45 000 запусков на 10 attention-слоёв.
Профиль: 61.0 с attention (10.3 TFLOPS, ~8 % от ~130 TFLOPS FP16 tensor у 3060 Ti).
`--att-mb 512` (tq 96) возвращает +5.5 % pp (1018.4 → 1074.0 на 96k N=4) — это симптом
узкого N, но остальное — материализация скоров и перечитывание K/V на каждый срез.

## Что сделано

`src/qwen35/q36_fa.cuh` — flash-style attention промпта на `mma.m16n8k16`: один запуск
на attention-слой на под-чанк, без буфера скоров, online softmax в exp2-домене, максимум
строки в регистрах квада (в первой версии он жил в shared и была гонка чтение/запись —
см. комментарий в файле), параметрическая причинность `j <= p0+i`, `oob` при
`P % kSlice != 0`. K и V делят один staging-буфер (`S.kv`); барьер между score-MMA
и загрузкой V делает переиспользование безопасным.

Четыре варианта плитки (`STRATA_Q36_FA_TILE`): 4x32, 8x32, 4x64, 8x64 (запросы × срез KV),
shared 41 216 / 65 536 / 64 256 / 94 720 Б. Launcher сам выводит форму и отказывает
на чужой геометрии — caller остаётся на cuBLAS.

## Врезка

`STRATA_Q36_FA_LAYER`: -1 — cuBLAS (по умолчанию), N — только слой N, `all` — все
attention-слои. `STRATA_Q36_FA_TILE` 0..3. `STRATA_Q36_FA_LOG=1` печатает строку запуска;
`STRATA_Q36_FA_CHECK=1` прогоняет обе ветки на FA-слое и печатает по головам
`max_abs`/`cos` против cuBLAS до гейта.

## Гейты

| Гейт | Метрика | Ожидание |
| --- | --- | --- |
| G1 | по головам `max abs` и `cos` против cuBLAS-att на 4k, P=2048 и P=9 | `cos >= 0.9999`, `max abs <= 2e-2` |
| G2 | сумма softmax диагонального запроса против cuBLAS | <= 1e-6 относительных |
| G3 | greedy-токены на 4k и 96k | совпадают с базой; near-tie — по топ-2 |
| G4 | профиль attention на 96k | <= 39 с на всех слоях (цель пилота; ~12–20 с при 25–40 % пика) |
| G5 | игла на 96k | не хуже базы |

Числа этих гейтов будут добавлены сюда по закрытии пилота.
