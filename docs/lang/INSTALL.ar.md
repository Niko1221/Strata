# تثبيت Strata

هذه الصفحة لكل من يثبّت Strata أو يحدّثه (الإصدار 0.2.22). استخدم **تطبيق سطح المكتب** للواجهة الرسومية، أو **الطرفية** للأمر `strata launch` وأدوات البرمجة. كلاهما يستخدم حزم محرّك جاهزة. التثبيت العادي لا يحتاج نسخة من المصدر ولا ملف `.bat` للبدء.

<a id="what-you-need"></a>

## ما تحتاجه

| الحاسوب | الدليل |
| --- | --- |
| Windows 10/11 أو Linux x86-64 مع بطاقة NVIDIA RTX | استخدم التطبيق أو الطرفية. يُنزّل محرّك بطاقتك تلقائياً. بطاقات NVIDIA الأقدم تستخدم محرّك CUDA 12 ([دليل البطاقات الأقدم](../OLDER_GPUS.md)). |
| Windows أو Linux x86-64 مع بطاقة AMD Radeon مدعومة | [دليل AMD](../AMD_HIP.md)، بما فيه جدول البطاقات والحزم. |
| Linux x86-64 مع Intel Arc | [دليل Intel Arc](../INTEL_ARC.md): ثبّت التعريف/بيئة الحوسبة وتحقق من متطلبات تحضير النموذج. |
| Mac بشرارة Apple Silicon، macOS 15 أو أحدث | [دليل Mac](../MAC.md). حزمة Mac لا تدعم Macs بمعالجات Intel. |
| AMD Ryzen AI Max / Strix Halo | [دليل Strix Halo](../STRIX_HALO.md) |
| NVIDIA DGX Spark (Linux ARM64) | [دليل DGX Spark](../DGX_SPARK_LINUX.md). استخدم الطرفية؛ لا يوجد تطبيق سطح مكتب لـ Linux ARM64. |

الاحتياجات من الذاكرة والقرص تعتمد على **النموذج والتكميم والسياق والميزات المفعّلة**. تحقق من [النموذج الذي يناسبك](../MODELS.md#pick-by-memory): حجم التنزيل لا يساوي استهلاك الذاكرة. الذاكرة الموحّدة تُحسب مرة واحدة. استخدم SSD واترك مساحة للملفات المساعدة ولتحضير النموذج. الأمر `--plan` في الطرفية يوضح ما ينقصك.

ثبّت تعريف بطاقة رسومية يدعم الحزمة التي تختارها. حزم CUDA 13 تحتاج تعريف NVIDIA 580 أو أحدث؛ البطاقات الأقدم تستخدم CUDA 12. متطلبات AMD وIntel في أدلتها. حزم تشغيل GPU المضمّنة لا تُغني عن تعريفات العتاد. تنزيل النماذج والتحديثات يحتاج اتصالاً بالإنترنت.

<a id="the-app"></a>

## التطبيق

1. افتح [أحدث إصدار](https://github.com/Niko1221/Strata/releases/latest).
2. نزّل المُثبّت الوحيد لنظامك. يوجد واحد لكل نظام، لا واحد لكل بطاقة رسومية:
   - **Windows:** شغّل `Strata-0.2.22-windows-x64-setup.exe`. يتثبّت لمستخدمك ولا يحتاج صلاحيات مدير.
   - **Linux:** اجعل `Strata-0.2.22-linux-x86_64.AppImage` قابلاً للتنفيذ ثم افتحه. إن لم يكن FUSE متاحاً، شغّل الملف الذي نزّلته مع `--appimage-extract-and-run`. [مساعدة Linux](../TROUBLESHOOTING.md).
   - **Mac:** افتح `Strata-0.2.22-macos-arm64.dmg`، اسحب Strata إلى Applications، ثم افتحه. [مساعدة Mac](../MAC.md).
3. على Windows وLinux لا يحتوي المُثبّت على محرّك. في التشغيل الأول يعرض التطبيق محرّك بطاقتك مع حجمه وزر **تنزيل** واحد، مع تقدّم وإمكانية الاستئناف. إن كنت نزّلت ملف المحرّك مسبقاً، اختر **لدي الملف بالفعل** فيُثبّت بلا إنترنت. ملف Mac يحتوي محرّك Metal الصغير بداخله.
4. اختر نموذجاً ومجلد حفظه، واتركه ينزّل، ثم ابدأ المحادثة.

أرشيفا `strata-engine-…` و`strata-control-…` في صفحة الإصدار مكوّنان لا مُثبّتان. المُثبّت هو نفس الملف للتثبيت الأول وللتحديث. لا يوجد مُثبّت سطح مكتب لـ Intel بعد؛ Intel Arc يعمل على Linux فقط عبر [الطرفية](../INTEL_ARC.md).

قد يستغرق التشغيل الأول وقتاً لفحص ملفات النماذج الكبيرة وتحضيرها. تابع التقدّم والسجلات؛ لا توجد مدة بدء ثابتة لكل نموذج وكل حاسوب. إغلاق تطبيق سطح المكتب يوقف المحرّك الذي يديره.

ترتيب المزوّدين الموصى به هنا هو **ISTA-DASLab، ثم Unsloth، ثم Gyro، ثم البقية** عندما يتوافق نموذج مناسب. قد تختلف توصيات التطبيق الحالية؛ اختر النموذج صراحةً عندما تريد مزوّداً بعينه.

<a id="the-terminal"></a>

## الطرفية

ثبّت مرة واحدة، ثم استخدم `strata launch`. تتضمن الطرفية Python وتنزّل المحرّك المناسب لحاسوبك.

**Linux / Mac**

```sh
curl -fsSL --connect-timeout 15 --max-time 120 https://github.com/Niko1221/Strata/releases/latest/download/install.sh -o install.sh && sh install.sh
```

**Windows PowerShell**

```powershell
irm -TimeoutSec 120 https://github.com/Niko1221/Strata/releases/latest/download/install.ps1 | iex
```

على Windows، افتح **طرفية جديدة** بعد ذلك. على Linux وMac، إن لم يُعثر على `strata`، استخدم المسار الكامل الذي يطبعه المُثبّت (عادةً `~/.local/bin/strata`) أو أضف ذلك المجلد إلى PATH.

```sh
strata launch
```

اتبع الشاشات لاختيار نموذج وسياق ومجلد حفظ وإعدادات وصول. تفتح شاشة المراقبة بعد البدء. استخدم العنوان الذي يطبعه Strata؛ نقطة النهاية المحلية الافتراضية هي `http://127.0.0.1:8080`. لا تفتح الطرفية متصفحاً إلا عند إضافة `--open`.

للسكربتات ووكلاء الذكاء الاصطناعي، افحص الخطة قبل التنزيل. هذا المثال يختار ISTA-DASLab Q2_0 صراحةً:

```sh
strata launch --family qwen --model q2_0 --plan
strata launch --family qwen --model q2_0 --yes --no-tui
```

الخيار `--no-tui` يترك الخادم يعمل في الخلفية. تحقق منه، أو اربط أداة، أو أوقفه:

```sh
strata launch --status
strata connect
strata launch --stop
```

إذا كان نموذج يعمل بالفعل بإعدادات مختلفة، أضف `--restart` لاستبداله؛ `--yes` وحده لا يعيد تشغيله. إعادة التشغيل تقطع الإجابات الجارية. راجع [كل خيارات التشغيل](../TERMINAL_LAUNCH.md) و[أوامر الطرفية المتقدمة](../TERMINAL.md) و[إعداد الوكلاء](../AI_SETUP.md).

<a id="updating"></a>

## التحديث

**تطبيق سطح المكتب:** افتح الإعدادات وابحث عن أدوات التحديث، وتحقق من التحديثات، واستخدم تحديث التطبيق أو المحرّك المعروض. أفرغ النماذج الجارية قبل استبدال المحرّك. ملفات النموذج وإعداداتك محفوظة.

**الطرفية:**

```sh
strata update --check
strata update
strata --version
```

مع نموذج محمّل، يقول `strata update` أي نموذج هو، ويسأل قبل إيقافه، وينزّل المحرّك الجديد بينما يظل النموذج يخدم، ثم يوقفه نظيفاً ويحدّث، ويسأل هل تريد إعادة تشغيله بنفس الإعدادات (أجب بـ"لا" فيبقى متوقفاً وتُطبع سطر البدء). إن فشل التحديث يبقى المحرّك القديم مستخدم ويمكن إعادة تشغيل النموذج. شاشة المراقبة وشاشة البدء تعرضان سطراً هادئاً عند توفر محرّك أحدث؛ اضغط `u` في المراقبة للتحديث. في السكربت لا تُطرح أسئلة: `--yes` وحده لا يوقف نموذجاً أبداً (خروج 7، بلا تغيير)، و`--stop-model` يسمح للتحديث بإيقافه و`--start-again` يعيد تشغيله بعده (خروج 8 إن لم يعد). الأمر التالي في الطرفية يستخدم مكوّن Control المحدّث. للتطبيق وControl والمحرّك أرقام إصدارات منفصلة، لذا قد تختلف.

استخدم `strata components rollback` للعودة إلى المحرّك السابق. انظر [تفاصيل التحديث](../../tools/packaging/UPDATES.md). لنسخ المصدر [سير عمل تحديث مختلف](../SOURCE_INSTALL.md#updating).

<a id="where-things-are-stored"></a>

## أين تُحفظ الأشياء

| العنصر | الموقع الافتراضي |
| --- | --- |
| محادثات سطح المكتب وحالة المضيف | `~/.strata` (أو `STRATA_HOME`) |
| مكوّنات المحرّك، Windows | `%LOCALAPPDATA%\Strata\components` |
| مكوّنات المحرّك، Linux / Mac | `$XDG_DATA_HOME/strata/components`، عادةً `~/.local/share/strata/components` |
| ملفات الطرفية | مجلد `terminal` بجانب `components`؛ المُثبّت يطبع المسار الدقيق |
| النماذج | المجلد الذي تختاره في التطبيق أو شاشات التشغيل؛ مكتبة نماذج موجودة تُعاد استخدامها |

يقترح تطبيق سطح المكتب عادةً `Documents/Strata/Models` لمكتبة جديدة. الطرفية تكتشف المجلدات المحفوظة من تثبيتات سابقة. استخدم المسار الذي يعرضه التطبيق أو `strata models list`، ولا تفترض اسم مجلد. `--data-dir` يغيّر مكان التنزيلات الجديدة؛ لا ينقل النماذج الموجودة إلا مع `--move-data`. انظر [اكتشاف النماذج](../TERMINAL_LAUNCH.md#models-you-already-have).
