# Strata: شغّل نموذج ذكاء اصطناعي كبير على حاسوبك — دليل عملي بالعربية

هذه المقالة مقدمة عربية لاستخدام Strata، مبنية على وثائق الإصدار 0.2.22. لا تحتوي على ادعاءات سرعة أو توافق غير موثّقة. للتنزيل والتثبيت التفصيلي راجع [دليل التثبيت بالعربية](INSTALL.ar.md)؛ وللمختصر الإنجليزي راجع [README بالعربية](README.ar.md).

## لماذا Strata؟

معظم النماذج الكبيرة تعمل على خوادم بعيدة: ترسل سؤالك إلى جهة أخرى وتنتظر الإجابة. Strata يذهب إلى الاتجاه المعاكس — ينزّل النموذج إلى جهازك ويشغّله هناك. المحادثة والكود والصور تبقى على جهازك، ولا يحتاج المشروع إلى حساب.

المشروع مفتوح المصدر برخصة MIT، وله واجهتان رئيسيتان:

- **تطبيق سطح المكتب**: نافذة فيها محادثة وملفات ومعاينة كود حيّة. مناسب إذا لم ترد استخدام الطرفية.
- **تطبيق الطرفية**: أمر واحد للتثبيت ثم `strata launch`. مناسب للسكربتات والخوادم وأدوات البرمجة.

صفحة الويب التي تخدمها الطرفية تدعم العربية أيضاً: افتح About > Settings واختر `العربية`. ولواجهة الأوامر نفسها يمكنك كتابة `STRATA_CLI_LANG=ar` قبل الأمر (أو `LANG=ar`) لتظهر الرسائل و`--help` بالعربية؛ بدون ذلك تبقى الإنجليزية هي الافتراضية.

## قبل أن تبدأ: هل جهازك مناسب؟

القاعدة الذهبية: **ذاكرة الوصول العشوائي (RAM) تحدد أي حزمة نموذج يمكنك تحميلها، وذاكرة بطاقة الرسوم (VRAM) تؤثر في السرعة**. لا تخلط بين حجم ملف التنزيل واستهلاك الذاكرة عند التشغيل؛ الذاكرة الموحّدة (كما في Apple Silicon وStrix Halo) تُحسب مرة واحدة.

| العتاد | ملاحظة |
| --- | --- |
| NVIDIA GeForce RTX 20 / 30 / 40 / 50 | المسار الأكثر توثيقاً |
| AMD Radeon RX 7700 / 7800 / 7900، RX 9060 / 9070، AI PRO R9700 | دليل HIP مخصّص؛ RX 6800 / 6900 تجريبي |
| Intel Arc | Linux فقط |
| Apple Silicon M1 أو أحدث | حزمة Metal داخل ملف DMG |
| AMD Ryzen AI Max / Strix Halo، NVIDIA DGX Spark | أدلة مخصّصة |

للتأكد من حجم الذاكرة المطلوب، ابدأ دائماً بأمر الفحص الذي لا يغيّر شيئاً:

```sh
strata launch --family qwen --model q2_0 --plan
```

يخبرك هذا الأمر بما ينقصك قبل أن تنزّل عشرات الغيغابايتات. استخدم SSD واترك مساحة إضافية لتحضير النموذج.

## الطريقة الأولى: تطبيق سطح المكتب

1. افتح [صفحة الإصدارات](https://github.com/Niko1221/Strata/releases/latest).
2. نزّل مُثبّت نظامك فقط: ملف Windows، أو AppImage لـ Linux، أو DMG لـ Mac.
3. على Windows/Linux لا يحتوي المُثبّت على المحرّك. عند التشغيل الأول يعرض التطبيق المحرّك المناسب لبطاقتك وحجمه وزر **Download** مع إمكانية استئناف التنزيل. إن كان لديك ملف المحرّك مسبقاً، اختر **I already have the file**.
4. اختر النموذج ومجلد الحفظ، وانتظر التنزيل، ثم ابدأ المحادثة.

## الطريقة الثانية: الطرفية

**Linux / Mac:**

```sh
curl -fsSL --connect-timeout 15 --max-time 120 https://github.com/Niko1221/Strata/releases/latest/download/install.sh -o install.sh && sh install.sh
```

**Windows PowerShell:**

```powershell
irm -TimeoutSec 120 https://github.com/Niko1221/Strata/releases/latest/download/install.ps1 | iex
```

بعد التثبيت على Windows افتح طرفية جديدة. ثم:

```sh
strata launch
```

تتبع الشاشات اختيار النموذج والسياق ومجلد الحفظ. العنوان الافتراضي هو `http://127.0.0.1:8080`. لا يفتح Strata متصفحاً إلا عند استخدام `--open`.

أوامر مفيدة بعد الإعداد:

```sh
strata launch --status      # ما الذي يعمل الآن؟
strata connect              # كيف أربط أداتي؟
strata launch --stop        # إيقاف الخادم
strata components rollback  # العودة إلى المحرّك السابق
```

## أي نموذج أختار؟

الترتيب الموصى به في الوثائق: **ISTA-DASLab أولاً، ثم Unsloth، ثم Gyro** عندما يتوافق حزمة مناسبة. Gyro يستهلك ذاكرة أقل لكنه أبطأ حالياً. عائلات النماذج الموثّقة:

- **Qwen3.8-Flash-Next**: خيارات مثل Q2_0 وIQ2_XS وIQ3_XXS وIQ3_S من ISTA-DASLab، وCoder (IQ1_M) للكود.
- **Tencent Hy4-Flash**: حزم SQ-64 وSQ-96 وSQ-128، الرقم يشير إلى ذاكرة النظام المستهدفة.
- **Qwen3.6-35B-A3B** و**Inkling 2 Mini**.

القاعدة العملية: ابدأ بالحزمة الأصغر التي تناسب ذاكرة جهازك، وجرّبها، ثم انتقل إلى أكبر حزمة تتسع لها. راجع [جدول التوافق](../MODELS.md).

## ربط أدوات البرمجة

Strata يوفّر واجهة برمجة متوافقة مع OpenAI وAnthropic على العنوان المحلي، لذلك يمكن لأدوات مثل Claude Code وCodex CLI وOpenCode وHermes Agent استخدامه بدل خادم بعيد. شغّل:

```sh
strata connect
```

تعرض الأداة تعليمات الإعداد الخاصة بها، ويمكنك التحقق بـ `strata connect <app> --check`.

## التحديث

- **التطبيق**: الإعدادات → بحث عن تحديثات، ثم تحديث التطبيق أو المحرّك. أفرغ النماذج الجارية قبل استبدال المحرّك.
- **الطرفية**: `strata update --check` ثم `strata update`. مع نموذج محمّل يسأل Strata قبل إيقافه، ويُنزّل المحرّك الجديد أثناء بقاء النموذج في الخدمة، ثم يعيد تشغيله إن اخترت ذلك.

## أخطاء شائعة

| العَرَض | أول خطوة |
| --- | --- |
| `strata` غير معروف بعد التثبيت | افتح طرفية جديدة على Windows؛ على Linux/Mac أضف `~/.local/bin` إلى PATH |
| نفاد الذاكرة | شغّل `--plan`، واختر حزمة أصغر أو قلّل السياق `--context` |
| الصور لا تعمل | تأكد من تفعيل `--vision`، وتحقق من أن النموذج يدعم الصور |
| الخادم لا يستجيب | `strata launch --status` ثم راجع [استكشاف الأخطاء](../TROUBLESHOOTING.md) |
