# Sponsor logos

Olares wordmarks from the official brand kit linked on [olares.com/one](https://www.olares.com/one) ("Brand kit", `BrandKit_Olares.zip`, `SVG/Standard/`). Downloaded 22 November 2026; the SVG artwork is unchanged.

- `olares-logo-color.svg` is the kit's `logo_color.svg`, for light backgrounds.
- `olares-logo-white.svg` is the kit's `logo_white.svg`, for dark backgrounds.

The kit's usage guide asks that the logo is scaled in proportion, kept clear of other elements and not recoloured. Names and brand marks belong to their owners.
