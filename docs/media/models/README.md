# Model logos

Small Qwen and Hunyuan marks from [LobeHub Icons](https://github.com/lobehub/lobe-icons), used to identify model families. Qwen downloaded 23 October 2026, Hunyuan 22 November 2026; SVG artwork is unchanged.

- [Qwen source](https://github.com/lobehub/lobe-icons/blob/master/packages/static-svg/icons/qwen-color.svg)
- [Hunyuan source](https://github.com/lobehub/lobe-icons/blob/master/packages/static-svg/icons/hunyuan-color.svg)

The icon library is [MIT licensed](LICENSE), copyright 2023 LobeHub.

The Thinking Machines wordmark (`thinking-machines.png`, and `thinking-machines-white.png` for dark backgrounds) is not in that library and is not covered by its licence. It comes from the image at the top of Thinking Machines Lab's own [Inkling 2 Mini model card](https://huggingface.co/thinkingmachines/Inkling-2-Mini), downloaded 22 November 2026. It was trimmed to the lettering, scaled down and put on a transparent background. The white file is the same lettering in white.

Model names and brand marks belong to their respective owners.
